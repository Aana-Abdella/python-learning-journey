## How To Study

1. Read the topic's `concepts.md`.
2. Open the existing `.py` examples and predict their behavior.
3. Run one small example at a time.
4. Use `practice.md` for a challenge, hint, and external problem source.
5. Explain the solution in your own words before moving on.

```text
understand -> predict -> code -> run -> inspect -> test -> explain -> repeat
```

For every problem, identify the input, output, rules, changing state, and edge cases. Test boundary values, not only normal examples.

## Practice Sources

- [Python Tutorial](https://docs.python.org/3/tutorial/): official language guide.
- [Python Standard Library](https://docs.python.org/3/library/): reference documentation.
- [Exercism Python Track](https://exercism.org/tracks/python/exercises): incremental, mentored exercises.
- [HackerRank Python](https://www.hackerrank.com/domains/python): short challenges.
- [Codewars Python Kata](https://www.codewars.com/kata/search/python): difficulty-based practice.
- [Project Euler](https://projecteuler.net/archives): mathematical problem solving.

Solve locally first, then compare approaches. Do not copy a solution before you can explain it.
