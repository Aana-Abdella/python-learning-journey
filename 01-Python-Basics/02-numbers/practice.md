# Numbers: Practice Lab

## Learn Faster

Estimate the answer before running arithmetic. Use named intermediate values and test with small numbers first.

## Tricky Problems

1. Predict the difference between `7 / 2`, `7 // 2`, and `7 % 2`.
2. Write an even-or-odd checker using `%`.
3. Calculate a bill with tax and a percentage discount without rounding intermediate values.
4. Explain why `0.1 + 0.2 == 0.3` may be false.
5. Create a score summary that calculates total, range, product, and average.

## Method

Translate words into formulas. Check units, operator precedence, zero denominators, and boundary values. For decimals, compare using a tolerance when exact equality is unsafe.
