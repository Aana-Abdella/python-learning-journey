# Strings: Practice Lab

## Learn Faster

Trace strings by writing indexes under each character. Test every transformation on empty text, extra spaces, mixed case, and punctuation.

## Tricky Problems

1. Predict `"Python"[-1]`, `"Python"[1:4]`, and `"Python"[::-1]`.
2. Normalize a username by trimming spaces and converting case.
3. Count words without counting repeated whitespace as empty words.
4. Explain why `text.upper()` does not change `text` unless the result is assigned.
5. Build a formatter using an f-string and numeric precision.

## Method

Separate parsing from formatting: first clean and split the input, then calculate, then build the final message.
