# Sets: Practice Lab

## Learn Faster

Draw two circles for set problems. Label shared values, values in only one set, and all unique values before using operators.

## Tricky Problems

1. Explain why `{}` is a dictionary and `set()` is an empty set.
2. Find common interests between two lists using a set.
3. Preserve order while removing duplicates without relying on set order.
4. Predict the result of union, intersection, and difference.
5. Explain why a list cannot be an element of a set.

## Method

Choose a set when uniqueness or membership matters more than order. Convert back to a list only when the next operation needs ordering.
