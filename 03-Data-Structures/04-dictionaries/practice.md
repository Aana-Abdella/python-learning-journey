# Dictionaries: Practice Lab

## Learn Faster

Write the key design first: what uniquely identifies each record? Then decide whether missing keys are errors or expected cases.

## Tricky Problems

1. Predict the difference between `data["missing"]` and `data.get("missing")`.
2. Count the frequency of each word in a sentence.
3. Group students by grade using a dictionary of lists.
4. Safely update nested data without accidentally replacing a whole record.
5. Explain why dictionary keys must be hashable.

## Method

Use `.items()` when both key and value are needed. Build one correct record first, then generalize to many records.
