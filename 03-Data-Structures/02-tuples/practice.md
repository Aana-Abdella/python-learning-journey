# Tuples: Practice Lab

## Learn Faster

Practice converting between a fixed record and named variables. Use unpacking to make data flow visible.

## Tricky Problems

1. Explain why `(5)` is an integer but `(5,)` is a tuple.
2. Unpack a tuple into `first`, `middle`, and `last` values.
3. Return both a minimum and maximum from a function as one tuple.
4. Explain what happens when the number of variables does not match the tuple length.
5. Identify whether a tuple containing a list is fully immutable.

## Method

Use tuples for fixed structure and lists for changing membership. Name unpacked values clearly, and test malformed record lengths.
