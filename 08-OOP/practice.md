# OOP: Practice Lab

## Learn Faster

Start with a function. Introduce a class only when state and behavior belong together or multiple objects share the same interface.

## Tricky Problems

1. Explain why instance methods need `self`.
2. Create a `Student` class with scores and a method for average.
3. Decide whether a property belongs to the instance or the class.
4. Compare composition and inheritance for a simple library system.
5. Write a class whose methods do not expose unnecessary internal state.

## Method

Identify object state, allowed operations, and invariants. Keep constructors small and methods focused. Test objects through public behavior.
