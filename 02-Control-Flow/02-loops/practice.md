# Loops: Practice Lab

## Learn Faster

For every loop, write four labels: initial state, condition, body, and update. Trace three iterations on paper before running it.

## Tricky Problems

1. Explain why `range(1, 4)` produces three values, not four.
2. Find the infinite-loop bug when `continue` skips the counter update.
3. Use `for ... else` to search for a missing value.
4. Build a guessing game with a finite attempt counter.
5. Explain why removing list items during iteration can skip values.

## Method

Choose `for` for known items and `while` for changing conditions. Use an accumulator for totals, a counter for quantities, and `break` when the answer is found.
