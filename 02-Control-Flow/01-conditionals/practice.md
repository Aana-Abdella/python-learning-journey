# Conditions: Practice Lab

## Learn Faster

Write the decision table before writing `if` statements. Include values just below, at, and above every boundary.

## Tricky Problems

1. Predict which branch runs when `score = 90` and `if score >= 50` appears before `elif score >= 85`.
2. Build a grade calculator that rejects scores outside 0 to 100.
3. Design access rules requiring either an administrator or an adult with an ID.
4. Explain the difference between `==` and `is` using two equal lists.
5. Use short-circuit evaluation to avoid accessing an attribute on `None`.

## Method

List outcomes from highest priority to lowest. Make ranges non-overlapping and test all boundaries. Keep input conversion and validation separate from decision logic.
