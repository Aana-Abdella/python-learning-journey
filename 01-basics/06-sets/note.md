# SET
  => used to store multiple items in a single variable.
  -it is built in pyhton to store collection of data.

# Characterictics
   - untouchable
   - unchangeable
   - unordered
   - Duplicate not allowed, 
       - True and 1 are considered the same values:
       - False and 0 is considered the same value:  so both are treated as duplicates.

# Methods and Constructors
   len() - to get the length.
   type() - to get type of data types.
   set() - to make set.
