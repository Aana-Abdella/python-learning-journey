# Function Fundamentals: Practice Lab

## Learn Faster

Write the function contract before implementation: inputs, output, side effects, and invalid cases. Test the return value directly.

## Tricky Problems

1. Predict why a function using `print` but no `return` produces `None` when assigned.
2. Find the unreachable statement after `return`.
3. Compose average, grade, and pass-status functions.
4. Refactor a script that mixes input, calculation, and output.
5. Write three assertions for one small function.

## Method

Keep one responsibility per function. Prefer returning data and printing only at the interface boundary.
