# Parameters And Arguments: Practice Lab

## Learn Faster

For every call, underline positional arguments and label keyword arguments. Predict the binding before executing.

## Tricky Problems

1. Explain why `function("A", name="B")` can assign one parameter twice.
2. Design a function with required parameters followed by optional ones.
3. Use keyword-only arguments to make a configuration call safer.
4. Write a function that accepts a list but never mutates it.
5. Explain the difference between passing a value and passing a reference to a mutable object.

## Method

Give parameters domain names, not generic names. Keep interfaces small and reject combinations that are ambiguous.
